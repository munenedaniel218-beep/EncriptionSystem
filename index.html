Cipher Vault

Encrypt a message or a file with a password. Only the same password can decrypt it.

Any file type, up to 10 MB. If a file is chosen, it is encrypted instead of the message. 



            

            

            

        


    



    

    


        

        

        

        

        

        


            

            

        


        

        


        


            

            


            

        


    



    

    


        How it works

        

            Your password is stretched into a 256-bit key with
            PBKDF2 (SHA-256, 250,000 rounds)
            and a random salt.

            The message or file is then encrypted with
            AES-256-GCM using a random IV.

            GCM also adds an authentication tag, so a wrong
            password or any edit to the data makes decryption fail.

            The original file name is encrypted together with
            the contents.

            The output is salt + IV + ciphertext in Base64,
            saved as a .txt file so it can be sent anywhere.

            Everything runs in your browser; nothing is uploaded.
